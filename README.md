# RideWise

RideWise is a rideshare management app that combines ride requests from platforms like Uber and Lyft into one interface to help drivers compare trips, reduce app switching, and choose better ride opportunities.

## Usage

RideWise is designed to provide drivers with a single interface for viewing and comparing rides from multiple rideshare platforms.

Example workflow:

```text
1. Receive available ride requests.
2. View rides from supported platforms in one dashboard.
3. Compare estimated earnings, distance, and other trip details.
4. Identify the better ride opportunity.
5. Accept the preferred ride and manage availability across platforms.
```
