# Contributing to RideWise

Thank you for your interest in contributing to RideWise!

## How to Contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Make your changes.
4. Test your changes.
5. Commit your work with a clear commit message.
6. Push the branch to your fork.
7. Open a pull request describing what you changed and why.

You can also contribute by opening issues, or helping with existing issues and documentation.

## Code Style

Keep your code readable, and consistent with the existing project.

- Use clear variable and function names.
- Keep functions focused on one task.
- Add simple comments above each line of the code you write explaining what it does.
- Follow the formatting style already used in the project.

## Testing

Before submitting a pull request:

- Make sure the application runs correctly.
- Test the feature or bug fix you changed.
- Make sure existing functionality still works.

## Documentation

Documentation should be clear and easy for new contributors to understand.

When adding or changing functionality:

- Update the README or related documentation when needed.
- Explain new features and important behavior.
- Add examples when they make the feature easier to understand.
- Keep comments and documentation up to date with the code.

Important project decisions and discussions should be documented publicly whenever possible.

## Reporting Bugs

If you find a bug, please open a GitHub Issue with a clear description of the problem.

Before opening a new issue, check whether the problem has already been reported.

## Proposing New Features

Feature ideas are welcome.

Open a GitHub Issue and describe:

- The feature you would like to see.
- The problem it would solve.

## Community Guidelines

RideWise aims to maintain a welcoming and respectful open source community.

Please:

- Be respectful and constructive.
- Welcome new contributors.
- Give helpful feedback.
- Stay focused on the issue being discussed.
- Respect different ideas and experience levels.
- Keep project discussions public when possible so everyone can participate and learn.

Any disrespectful behavior will not be accepted.

Not every contribution or feature proposal will be included in the project. 

Thank you!
